# ENMA301 Homework #4

## Description
This program calculates the transmitted light intensity through a multilayer system 
by accounting for reflection losses at interfaces and absorption within materials by 
using Beer-Lambert Law

## How it works
1. Applies reflection loss at each interface
2. Applies exponential absorption through each material layer
3. Repeats this process across all layers
4. Outputs final transmitted intensity and percent transmission

## Output
I made it so the program prints both the final transmitted intensity in W/m² and 
the % of light transmitted
